> **Google Antigravity** 宣布桌面应用推出 `SSH` 连接功能，能连上远程 `Linux` 主机，项目和 `agent` 在远程运行，本地窗口关掉后进程也不中断。

**Google Antigravity** 桌面应用推出 `SSH` 连接功能，可从侧边栏或命令面板连接远程 `64 位 Linux` 机器。

### [Gemini API 预览推出工具按需加载功能](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/) `#5`
> **Google** 宣布 `Gemini API` 预览推出 `Tool Retrieval` 功能，AI agent 无需每次请求发送完整工具库，可按需加载工具定义并接入数百种工具。

**Google** 在 **Gemini API** 预览推出 `Tool Retrieval` 功能，AI agent 可按需加载工具参数结构，无需每次请求发送完整工具定义，支持接入数百种工具并减少 tokens 消耗。

开发者只需添加 `tool_search` 工具并标记暂缓加载的工具，模型先看到工具名称和描述，需要时再加载完整参数结构。

该功能仅支持 `Interactions API`，兼容 `Gemini 3.6` 及后续所有模型，远程 `MCP` 服务器同样支持按需加载。

`Tool Retrieval` 不单独收费，tokens 按所用模型标准费率计费。

**火山引擎**宣布，豆包实时音视频通话模型 `SeedRealtime 1.0` 的 API 服务正式上线。

该模型将声音、画面、时序与表达统一到同一个端到端模型中，支持边看、边听、边说的实时交互，能在持续理解场景变化后于合适时机主动开口。

该服务可用于语音助手、智能硬件、陪伴式应用、实时客服等场景。
