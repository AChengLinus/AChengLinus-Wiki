### [崔添翼：一切皆插件是 DeepSeek Harness 初心](https://www.zhihu.com/question/2089740005770008568/answer/2090104616759325588) `#2`
> **DeepSeek Harness** 近日发布 `v0.2.1-alpha.1` 预发布版本，新增实验性 `Claude Code Mods` 兼容层，但目前无法让所有 `Claude Code Mods` 无缝运行。**DeepSeek Harness** 组成员**崔添翼**发文表示，兼容层用于验证 `Claude Code Mods` 扩展能力是否为一切皆插件架构所提供能力的一个子集。

**DeepSeek Harness** 近日发布 `v0.2.1-alpha.1` 预发布版本，新增实验性 `Claude Code Mods` 兼容层。官方在发布说明中写明，该阶段主要目的是验证 `Claude Code Mods API` 的功能大致为 `DeepSeek Harness` 插件能力的一个子集，而非为用户提供实际的完整兼容性。

兼容层作者、**DeepSeek Harness** 组成员 **崔添翼** 在知乎回应表示，该兼容层属于 `alpha` 版本中的实验性功能，尚有很多不完善之处，不能保证百分之百兼容，目前无法让所有 `Claude Code Mods` 在 **DeepSeek Harness** 中无缝运行；但从技术上看，若这是值得投入的目标，未来有可能做到。

他强调，“一切皆插件”是 **DeepSeek Harness** 立项之初就确立的核心理念，并非被迫或模仿别人，其意义包括：用插件和社区满足多样化用户需求（创造模式已允许 `Agent` 编写并安装插件）、以插件化满足不同行业企业部署需求，以及推进 `Agent` 自进化命题，团队正在招聘相关研究员。
