### [OpenAI 发布 Images 2.6：支持动画 GIF 生成，提速 50%](https://openai.com/index/introducing-images-2-6/) `#1`
> **OpenAI** 发布图像模型 `Images 2.6`，同步上线 ChatGPT、Codex 和 API 端，核心更新包括动画 GIF 生成、参考图复用和更快的生成速度。ChatGPT 新增 GIF 能力，用一句话描述动作或上传一张照片，就能把静态角色或吉祥物图变成循环播放的动图。参考图功能则可把人物、宠物或角色的图片保存后反复调用。面向开发者的两款新 API 模型 `GPT-Image-2.6 Flare` 和 `Sunburst` 一并上线，官方称生成速度比此前提升 **50%**，图片标注功能同步进入 API。

**OpenAI** 发布图像模型 `Images 2.6`，在 `ChatGPT`、`Codex` 和 `API` 端同步上线。新模型能把文字提示或上传的照片变成动画 `GIF`，生成后可调整播放速度、逐帧编辑，还能把自己、宠物或角色的图片存为参考图反复使用，无需重复上传。

`API` 端同步推出 `GPT-Image-2.6 Flare` 和 `Sunburst` 两款模型，官方称生成速度比此前提升 **50%**：画质设为低档时 `Flare` 最快 **6 秒**生成一张图片，还改进了海报、产品图等专业视觉的排版质量；`Sunburst` 面向更高画质，中高档设置下多次编辑保持细节更一致。开发者可用图片标注指定修改位置，`complexity` 参数分低、中、高三档调节规划程度，缺省为高、不额外收费，另支持导出 `SVG`。

`Images 2.6` 今天起面向全部订阅档位开放，覆盖网页、桌面和移动端；两款 `API` 模型按 `token` 计价，图像输入每百万 `token` **8 美元**、输出 **30 美元**、缓存输入 **2 美元**，与 **2.5** 版相同。

### [腾讯混元 Hy4 正式版发布](https://hy.tencent.com/research/hy4) `#2`
> 腾讯混元发布大语言模型 `Hy4` 正式版，首次加入视觉和电脑操作能力，可分析复杂图表、调用工具，并结合命令行与图形界面处理专业软件任务，适用于开发、金融、办公和科研等场景。腾讯称，`Hy4` 在真实金融任务众测中位居开源模型第一，内部评测幻觉率从预览版的 **15.76%** 降至 **5.45%**；但在前沿数学、长程开发等高难度测试中，与顶尖闭源模型仍有明显差距。模型已上线 WorkBuddy、腾讯云和 OpenRouter，权重计划近期开源，主打更高性价比和更快推理速度的 `Hy4 Flash` 也计划近期发布。

腾讯混元发布最新一代大语言模型 `Hy4` 正式版，官方称 `Hy` 首次跻身最强开源模型之列。相比 `Hy4 preview`（总参数 **770B**、激活参数 **49B**、上下文 **1M**），`Hy4` 首次引入视觉能力和电脑操作，能结合命令行与图形界面完成专业任务。

游戏开发评测较 preview 提升 **19.1%**；与腾讯金融科技 `FiT` 组织 **213 位**从业者众测 **579 个**真实金融任务，综合得分 **3.04** 居开源模型第一，幻觉率从 **15.76%** 降至 **5.45%**；办公助手通过 `WorkBuddy` 连通企业微信聊天、邮件、文档与日程，可识别待办、提醒截止；科研评测 `TenureTrail` 居开源第一，结合 `Hyra 2.0` 将内部预训练吞吐提升 **20.1%**，并开源协同研发的 `HyCell` 与 `HyPDE`。

`Hy4` 已在腾讯云和 `OpenRouter` 上线，API 价格与 preview 持平：每百万 token 输入 **0.834 美元**、输出 **2.501 美元**。
