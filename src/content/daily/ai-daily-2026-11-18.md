### [OpenAI 发布 GPT-6.2 Astra 与 Sol，分别面向复杂任务和日常工作](https://openai.com/index/introducing-gpt-6-2-astra-sol/) `#1`
> **OpenAI** 发布 `GPT-6.2 Astra` 和 `Sol`。`Astra` 面向复杂任务，在多步工作评测中比前代有显著提升，同时成本更低。`Sol` 主打日常工作，在编程评测中得分接近 `Astra`，单项成本约为后者的五分之一。两款模型已在 **ChatGPT Work**、**Codex** 和 **API** 上线。**Pro 200** 订阅用户可在 **Codex** 对 `Sol` 启用 `Ultrafast`。

**OpenAI** 发布 **GPT-6.2 Astra** 和 **Sol**。

`Astra` 侧重复杂编程、科研和长程任务，`Sol` 面向日常多步工作。在 **OpenAI** 的多步工作评测 **Agents’ Last Exam** 中，`Astra` 比前代高 **5.2 分**，单项成本不到前代的三分之一。在 **Cognition** 的编程评测 **FrontierCode 2.0** 中，两款都用最高推理档，`Sol` 与 `Astra` 分差不超过 **0.5 分**，单项成本约为后者的五分之一。

两款已在 **ChatGPT Work** 和 **Codex** 向 **Plus**、**Pro**、**Enterprise** 和 **Edu** 用户开放，API 同步上线。**Pro 500** 两款均可用 `Ultrafast`，**Pro 200** 可先在 `Codex` 对 `Sol` 使用，符合条件的企业和教育工作区须由管理员启用。

API 每百万 token 的标准短上下文费率，`Astra` 输入 **8 美元**、缓存输入 **0.40 美元**、输出 **40 美元**，`Sol` 对应 **2、0.10、10 美元**。

**OpenAI** 也收紧了高风险网络安全协助的限制，计划通过 **Daybreak** 向获准的防御机构开放两款模型。
