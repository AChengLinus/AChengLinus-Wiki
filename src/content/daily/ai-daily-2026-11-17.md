### [阿里巴巴发布 Qwen4-Max：官方称成本降 58%](https://qwen.ai/blog?id=qwen4-max) `#1`
> **阿里巴巴**发布 `Qwen4-Max`，主干参数 **2.4 万亿**，每个 `token` 激活 **710 亿**参数，支持原生视觉与百万 `token` 上下文。根据官方数据，在 `Terminal-Bench 4.0` 等基准及多类能力评测中，它均较前代明显提升，`token` 消耗和 `API` 价格大幅下降。目前模型已上线千问 AI 平台，接入千问 APP、千问办公与 `Qoder` 等应用。同时，官方称 `Qwen4` 系列中小尺寸模型将陆续开源。

阿里巴巴正式发布新一代基座大模型 `Qwen4-Max`，基于全新稀疏 `MoE` 架构，主干参数 **2.4T**，每个 `token` 激活 **71B** 参数，并配有 **328B** `N-gram Embedding` 参数，支持原生视觉与百万 `token` 上下文窗口，预训练全程未出现 `loss spike`。

在能力与效率方面，官方数据显示其在 `Terminal-Bench 4.0`、`Last Secure Code Bench` 等基准以及知识、代码、问答、`STEM` 等多类评测中均较前代 `Qwen3.8-Max` 明显提升，`Terminal-Bench 4.0` 的 `token` 消耗减少约 **48%–49%**，任务平均费用降低 **58%**。

`API` 定价同步下调，输入、输出每百万 `token` 分别为 **1.5 美元**和 **4.5 美元**，隐式缓存降至 **0.075 美元**（降幅 **70%**）。

目前模型已上线千问 AI 平台与 `QwenCloud`，接入千问 APP、千问办公、`Qoder`、`Qwen Studio` 等应用，千问 APP 会员上线期间可限免体验；官方同时开源了 `Qwen-Live-Delivery-Plugin`，并表示系列中小尺寸模型将陆续开源。

> **Antigravity** 负责人宣布，`Argon`、`Carbon`、`Hydrogen` 的上下文窗口扩至两倍，每轮交互的压缩次数也大幅减少。他称减少压缩也能加快任务完成，并表示更大订阅方案正在推进，原生电脑操作功能将很快推出。

**Antigravity** 负责人 **Varun Mohan** 宣布，已将 `Argon`、`Carbon` 和 `Hydrogen` 的上下文窗口扩大一倍，每轮用户交互的压缩次数降至原先的约 **1/3.5**。压缩指上下文空间不足时压缩已有内容、模型再重新读取的过程。

**Mohan** 回应用户提问时称，压缩本身耗时较多，减少压缩也有助于任务更快完成。有用户发帖称，此次更新把上下文从 **256k** 提高到 **512k**。面对用户提出的更大订阅方案请求，**Mohan** 表示正在推进；原生电脑操作功能也将很快推出。

**上海人工智能实验室**发布并开源科学多模态模型`书生-S2.1 Flash`，采用**3200亿参数**`MoE`架构，支持分子图、晶体结构、蛋白质序列、光谱等十余类科学输入，可操作专业科研软件执行多步骤科研任务。

Perplexity 正式推出 `Monitor API`，可按设定周期追踪一个话题的新进展，或跟踪最多 **10** 个指定网页的文本变化，发现相关更新就通过 webhook 推送给应用。

监控按固定间隔或 cron 计划运行，可在 API 或 API Console 创建，密钥与 `Search`、`Agent API` 通用。

定价为每 **1000** 次成功运行或每抓取 **1000** 个 URL 收 **1 美元**。
