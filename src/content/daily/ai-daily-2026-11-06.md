### [Google 发布 Gemini Omni 1.2 Flash](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/) `#1`
> **Google** 推出视频模型 `Gemini Omni 1.2 Flash`，原生视频时长从 **10 秒**提升至最长 **15 秒**，还能多轮对话修改画面。用户可结合图片、动作片段和音频引导生成，改善人物和场景的一致性；新模型也增强了对白、口型同步和镜头控制。模型正在陆续上线 `Flow`、**Google Vids** 和 `Gemini` 等产品以及 `Gemini API`。

**Google** 推出 `Gemini Omni 1.2 Flash` 视频生成模型。模型原生生成和编辑视频的时长从上一代最长 **10 秒** 提升至 **15 秒**，用户可按秒设置时长，并通过多轮对话调整同一片段的背景、光线或画面比例。

用户还可以结合角色、产品或风格图片、最长 **3 秒** 的动作片段及音频提示引导生成；**Google** 称参考遵循更准确，人物和场景在镜头转换中更连贯。对白、口型同步、多说话人和连续镜头控制也有改善。

用户可先以 `360p` 或 `720p` 生成，再将成片放大至 `1080p` 或 `4K`；`720p` 视频价格为每秒 **0.07 美元**，较 `Omni 1.1` 下降 **30%**。

模型正陆续进入 `Flow`、`Google Vids` 和 `Gemini` 等产品，其中 `Gemini App` 正向 **Google AI Ultra** 订阅用户推出。**Google** 表示，快速体育动作、快速脚本变化和复杂物理效果仍需改进。

### [OpenAI 发布 GPT-6 Cyber 网络安全模型](https://openai.com/index/introducing-gpt-6-cyber) `#2`
> OpenAI 发布网络安全模型 `GPT-6 Cyber`，找漏洞能力更强，也更可靠地留在研究者设定的范围内。该模型已在 Firefox 和 Linux 内核中发现并验证数千个漏洞利用，目前向部分获批的 Daybreak Red 客户开放。

**OpenAI** 发布网络安全模型 `GPT-6 Cyber`，称其在关键网络安全基准上较上一代 `GPT-5.6 Cyber` 明显提升：`ExploitGym` 得分从 **32.1%** 升至 **48.5%**；越界测试中，不使用部署安全提示时 **99.93%** 的测试守在任务范围内，加上提示后为 **100%**。

**OpenAI** 研究人员已用该模型发现 Firefox 中 **81** 个此前未知、被 **Mozilla** 评为高危的漏洞，并为 **948** 个 Linux 内核漏洞开发出可用利用。

基于评测结果，**OpenAI** 按 `Preparedness Framework` 将 `GPT-6 Cyber` 归类为网络安全 `Critical` 级，高于 `GPT-5.6 Cyber` 的 `High` 级。

模型目前通过 `API` 和 `Codex` 向部分获批的 `Daybreak Red` 客户开放，后续将逐步扩大到全部 `Daybreak Red` 客户。

### [中国科大开源 RNA 基础模型，成果登上《自然》](https://doi.org/10.5281/zenodo.16754363) `#6`
> 中国科学技术大学团队发布开源 RNA 序列基础模型 `structRFM`，成果发表于《自然》。该模型用约 **2100 万**条序列与结构配对数据完成结构引导预训练，可预测 RNA 结构并推断功能，数据、模型权重和源代码均已开放。

**中国科学技术大学**宣布，该校医学影像智能与机器人（`MIRACLE`）实验室**周少华**教授、**熊鹏**特任研究员团队发布开源 `RNA` 序列基础模型 `structRFM`，相关成果发表于《自然》。

研究团队构建了约 **2100 万**条经计算注释的序列与二级结构配对数据，用结构引导掩码语言建模策略同时学习序列上下文与结构依赖。预训练后的模型仅需输入序列，即可提取序列级、核苷酸级和核苷酸对级特征。

`structRFM` 支持 `RNA` 二级结构与三级结构预测，以及剪接位点预测、`IRES` 识别、非编码 `RNA` 分类等功能推断任务，并可借助滑动窗口策略处理最长 **3000 nt** 的长非编码 `RNA`。

目前，团队已开放完整配对数据、模型权重和源代码。

### Cursor 推出 Live Apps：描述需求即可构建上线应用 `#8`
> **Cursor** 推出 **Live Apps**，用户通过 `Cloud Agent` 描述需求即可构建并部署 `Web` 应用。系统按需配置数据库、鉴权与托管，安全检查通过并确认后生成分享链接。

**Cursor** 推出 `Live Apps` 功能，用户启动一个 `Cloud Agent` 并描述想要的应用，Cursor 就会构建 `Web` 应用、按需启动 `Postgres` 数据库、配置基于 Cursor `SSO` 的身份验证并完成托管。

应用可共享给指定人员、群组或整个团队，访问均需通过 Cursor 登录，个人套餐还可以公开共享，而 `Teams` 和 `Enterprise` 团队默认关闭公开分享。

该功能现已面向所有已启用 `Cloud Agent` 的付费方案开放，不支持本地 `agent`，团队管理员可控制功能开关、公开分享和 `API key`，并取消发布任意应用。

### [OpenAI GPT-Live 外呼 API 正式发布](https://developers.openai.com/api/docs/guides/voice-sip) `#9`
> OpenAI 宣布，`GPT-Live` 外呼电话 `API` **正式发布**，对所有组织开放。开发者可以让语音智能体通过任意 `SIP` 中继服务商拨打电话，通话支持高清语音和按键收发。

OpenAI Realtime AI 负责人 **Justin Uberti** 宣布，`GPT-Live` 外呼电话 API 正式发布（GA），开发者可以让 Live 语音智能体通过任意 `SIP` 中继服务商（如 **Telnyx**、**Twilio**）向外拨打电话。
