### [Claude Code 桌面版更新优化多会话体验](https://x.com/ClaudeDevs/status/2110445844675838148) `#1`
> **Anthropic** 更新了 **Claude Code** 桌面应用，重点改善多个会话并排运行的体验，开会话更快，拆分工作更方便，也能随时看到每个会话在做什么。用户让 **Claude** 并行处理任务时，它会为每项任务开一个嵌套会话，完成后再把结果汇报回主会话。另外，**Claude** 会在工作中主动建议后续任务，一键就能另开会话，侧边栏也会标出哪些会话还在运行、哪些需要用户处理。

**Anthropic** 更新 `Claude Code` 桌面应用，围绕多会话并行改进会话启动、工作拆分和状态查看。

新会话界面可一键打开近期文件夹，用户还能把几个文件夹、一台 `SSH` 主机或云端保存为环境，直接在其中启动会话，并可为每个文件夹单独使用 `worktree`。

用户要求并行执行任务时，`Claude` 会为每项任务启动嵌套会话，完成后把结果汇报回主会话；`Claude` 主动建议的后续工作可一键作为独立会话运行，用 `/btw` 提出的旁支问题会在单独标签页打开，主会话继续运行。

侧边栏会标出哪些会话正在工作、哪些需要用户介入，会话内还有跟随计划更新的实时待办列表和总结本轮的回顾卡片。

用户更新桌面应用并新建会话即可使用。

### [Claude Code 新增闲置会话自动压缩](https://x.com/lydiahallie/status/2110484840256819380) `#2`
> **Anthropic** 介绍近期为 `Claude Code` 终端加入的闲置会话自动压缩功能，该功能可在缓存过期前把长对话压成摘要。用户可自行调整触发压缩的最低 `token` 数，或关闭该功能。

**Anthropic** 为 `Claude Code` 终端加入闲置会话自动压缩功能：默认达到 **200K** `token` 的对话闲置约 **54 分钟**后，会在 **1 小时**的 `prompt cache` 过期前压缩为摘要。

用户返回后只需重新处理摘要，而非整段对话，以节省用量，但 **Claude** 也将基于摘要而非完整上下文继续工作。

用户可调整触发压缩的最低 `token` 数，或关闭该功能；这两项配置需要 **v2.1.290** 或更新版本。

### [TypeSafe AI 更新 Jev，开放图像与长上下文功能](https://typesafe.ai/blog/jev-1-14) `#3`
> **TypeSafe AI** 发布 **Jev** 新版本，同时开放图像输入、图像目标定位和更长上下文等实验性功能。这些功能需要在 `API` 中主动开启，官方提醒，目前可靠性仍不足以支持生产场景。

**TypeSafe AI** 发布 `Jev 1.14.0`，通过 `jev-preview` 提供，并开放图像输入、`box` 类型和长上下文等实验性功能，需通过 API 请求头中的 `danger zone` 标记主动开启，官方尚不建议用于生产场景。

图像可放入状态、问题指令或判断标准中，`Jev 1.13` 和 `1.14` 均支持；用于定位图像目标的 `box` 类型仅支持 `1.14`，每个问题返回单个边界框。

两个版本开启长上下文后，单次请求和单个问题的上下文上限均为 **262k token**，但速度和准确率会下降。

新版本价格与 **1.13** 相同，每百万输入 token 为 **0.042 美元**，输出 token 免费。

### [Claude Platform 支持导出 OpenTelemetry 追踪](https://claude.com/resources/articles/agent-observability-on-the-claude-platform) `#10`
> **Anthropic** 将 `Claude Platform` 的 `OpenTelemetry` 追踪功能开放公测，开发者可把模型调用、工具使用和 `Agent` 会话的运行记录发送到已有的监控系统，用于排查失败、延迟和用量问题。
