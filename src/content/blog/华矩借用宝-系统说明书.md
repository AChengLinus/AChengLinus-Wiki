## 1. 系统概述

**华矩借用宝** 是一套面向检测/实验室机构的设备借用管理系统，支持设备台账管理、借用审批流转、调拨管理、归还管理等全流程数字化管理。

系统由三部分组成：
- **微信小程序端**：供普通用户进行设备浏览、借用申请、归还、调拨、查看记录
- **Web后台管理面板**：供管理员进行设备/用户管理、工单审批、数据导出、系统备份
- **Node.js API服务**：提供RESTful API接口，支持SQLite（开发）和MySQL（生产）双数据库模式

### 核心业务流程

```
设备浏览 → 选择设备 → 提交借用工单 → 管理员审批 → 领用设备
                                                          ↘
                                                    使用完毕 → 提交归还工单 → 管理员验收 → 设备回库
                                                                                            
用户间调拨：持有人 → 发起调拨 → 对方确认 → 设备转移
```

## 3. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端（小程序） | 微信原生小程序 (WXML/WXSS/JS) | 兼容微信 3.6.0 基础库 |
| 前端（管理端） | 原生 HTML5 + CSS3 + Vanilla JS | 单页应用，无框架依赖 |
| 后端服务 | Node.js + Express | 路由 + 中间件架构 |
| 数据库（开发） | SQLite (better-sqlite3) | 本地 data.db 文件 |
| 数据库（生产） | MySQL (mysql2) | 微信云托管 TencentDB |
| 部署 | Docker + 微信云托管 | Dockerfile 支持容器化部署 |
| 二维码 | 设备自带二维码/条码 | JSON 格式 encode 设备信息 |

### 关键依赖

**服务端 (server/package.json 推断):**
- express, cors: Web 框架
- better-sqlite3: SQLite 驱动
- mysql2: MySQL 驱动
- Node.js 20+

## 4. 数据库设计

系统共包含 10 张数据表：

### 4.1 用户表 (users)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 用户ID (如 u1, u6) |
| name | TEXT | 用户名 |
| role | TEXT | 角色: super_admin / admin / user / viewer |
| password | TEXT | SHA256 加密密码 |
| phone | TEXT | 手机号 |
| avatar | TEXT | 头像URL |
| createdAt | TEXT | 创建时间 |

### 4.2 设备表 (devices)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 设备编号 (如 HJJC-SB001) |
| name | TEXT | 设备名称 |
| model | TEXT | 型号规格 |
| assetCode | TEXT | 资产编号 |
| category | TEXT | 分类 (测量设备/辅助设备/软件/其他) |
| mainDevice | TEXT | 母设备编号（用于子设备关联） |
| oldCode | TEXT | 旧仪器编号 |
| status | TEXT | available / borrowed / transferring / fault |
| currentHolderId | TEXT | 当前持有人ID |
| extra | TEXT(JSON) | 扩展字段，包含部门、存放位置、财务信息、计量信息等 |
| createdAt/updatedAt | TEXT | 时间戳 |

### 4.3 借用记录表 (borrow_records)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 记录ID |
| deviceId | TEXT | 设备编号 |
| deviceName | TEXT | 设备名称 |
| borrowerId | TEXT | 借用人ID |
| borrowerName | TEXT | 借用人姓名 |
| status | TEXT | pending / approved / rejected / returned / return_pending |
| applyTime | TEXT | 申请时间 |
| approveTime | TEXT | 审批时间 |
| returnTime | TEXT | 归还时间 |
| returnStatus | TEXT | 归还时设备状态 (正常/故障/异常) |
| reason | TEXT | 借用事由 |
| pickupTime | TEXT | 领用时间 |
| expectedReturnDate | TEXT | 预计归还日期 |

### 4.4 借用工单表 (work_orders)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 内部ID |
| orderNo | TEXT UNIQUE | 工单编号 (WO+时间戳) |
| userId | TEXT | 申请人ID |
| userName | TEXT | 申请人姓名 |
| status | TEXT | pending / approved / rejected |
| deviceItems | TEXT(JSON) | 设备清单 [{deviceId, deviceName, model, assetCode}] |
| reason | TEXT | 事由 |
| pickupTime | TEXT | 领用时间 |
| expectedReturnDate | TEXT | 预计归还日期 |
| approverId/approverName | TEXT | 审批人信息 |
| applyTime/approveTime | TEXT | 时间戳 |

### 4.5 归还工单表 (return_work_orders)
结构与借用工单表类似，用于归还审批流程。

### 4.6 调拨记录表 (transfer_records)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 记录ID |
| deviceId/deviceName/deviceModel | TEXT | 设备信息 |
| fromUserId/fromUserName | TEXT | 转出方 |
| toUserId/toUserName | TEXT | 接收方 |
| initiatorId | TEXT | 发起方ID |
| status | TEXT | pending / approved / rejected |
| reason | TEXT | 调拨事由 |
| requestTime/approveTime | TEXT | 时间戳 |

### 4.7 通知表 (notifications)
支持类型: new_borrow, borrow_result, transfer_request, transfer_result, return_approval, return_result

### 4.8 其他表
- **phone_whitelist**: 手机号白名单（用于手机号快捷登录）
- **backups**: 数据备份存储
- **app_settings**: 系统设置（如自动备份间隔）

## 6. 使用手册 - 微信小程序

### 6.1 登录

1. 打开小程序，进入登录页面
2. **方式一（推荐）**：选择用户名 + 输入密码登录
   - 从下拉列表选择用户
   - 输入密码（默认 123456）
   - 勾选"记住密码"可在下次自动填充
3. **方式二**：手机号登录（需管理员先在白名单中添加）

### 6.2 首页 - 设备浏览

底部导航栏第一项 **"设备"** 页面展示所有设备列表。

**功能：**
- **搜索**：通过设备名称、型号、资产编号等关键词搜索
- **状态筛选**：全部 / 在库可用 / 已借出 / 调拨中 / 故障
- **查看详情**：点击设备进入详情页，查看完整信息（技术参数、计量信息等）
- **子设备**：主设备详情页会显示关联的子设备列表

### 6.3 借用设备

#### 单个借用
1. 在设备列表点击设备 → 进入详情页
2. 点击底部"申请借用"
3. 填写：领用事由（必填）、领用时间、预计归还日期、备注
4. 提交申请，等待管理员审批

#### 批量借用
1. 在设备列表页，**长按**任一设备进入多选模式
2. 勾选多个"在库可用"的设备
3. 点击底部"借用 (N) 台"按钮
4. 填写领用信息后提交

> 注意：子设备会跟随母设备自动关联借用，无需单独选择。

### 6.4 设备详情

设备详情页展示完整信息：
- **基本信息**：编号、名称、型号、资产编号、分类
- **财务信息**：购置日期、购入原值、供应商、是否固定资产
- **技术信息**：出厂编号、生产厂家、出厂日期、使用年限、技术指标
- **计量信息**：是否溯源、溯源方式、计量机构、计量周期、证书编号、有效期
- **位置信息**：归属部门、存放位置
- **关联设备**：母设备名称、子设备列表及各自状态

### 6.5 我的库存

底部导航 **"我的"** → **"我的库存"** 查看当前借用和持有的设备：
- 当前借用的设备列表
- 持有设备的调拨记录
- 点击设备可查看详情

### 6.6 借用/归还记录

底部导航 **"记录"** 页面展示用户的完整借用和归还历史：
- 借用记录（含状态：待审批/已通过/已拒绝/已归还）
- 调拨记录（含状态：待审批/已通过/已拒绝）

### 6.7 审批

底部导航 **"审批"** 页面：
> 注：仅管理员（admin/super_admin）可见此页

- **借用审批**：查看待审批借用工单 → 通过/拒绝 → 通过后设备自动标记为"已借出"
- **归还审批**：查看待审批归还工单 → 通过/拒绝 → 通过后设备自动标记为"在库可用"
- **调拨审批**：查看待处理的调拨请求 → 确认接收/拒绝

### 6.8 归还设备

1. 在"我的" → "我的库存" 中选择要归还的设备
2. 点击"申请归还"
3. 填写归还状态（正常/故障等）和备注
4. 提交归还工单，等待管理员验收

### 6.9 设备调拨

调拨用于设备在不同用户间转移持有权：

**场景一：主动调拨给他人**
1. 在"我的库存"中选择设备
2. 点击"调拨给他人"
3. 选择接收人
4. 对方在审批页面确认接收后，设备转移

**场景二：请求借用他人设备**
1. 浏览设备列表，找到已被他人借用的设备
2. 点击"请求借用"
3. 填写事由，请求发送给当前持有人
4. 持有人审批通过后，设备转移

### 6.10 通知中心

在"我的"页面顶部查看通知，包括：
- 借用审批结果通知
- 归还审批结果通知
- 调拨请求/结果通知
- 支持标记单条已读或全部已读

## 7. 使用手册 - 后台管理面板

后台管理地址：`http://服务器地址:3000/`（开发环境）
或 `https://hjjcsb.acheng9616.com/`（生产环境）

登录账号：`hjjcsb` / `123456`

### 7.1 仪表盘

展示全局统计数据：
- 设备总数 / 在库可用 / 已借出 / 故障
- 待审批借用工单数 / 待审批归还工单数
- 总用户数
- 最近10条工单动态
- 侧边栏自动显示待办角标

### 7.2 设备管理

**设备列表：**
- 支持搜索、按分类/状态筛选
- 支持分页浏览 + 列宽拖拽
- 每行显示：编号、名称、型号、分类、状态、当前持有人
- 操作：编辑 / 改状态 / 删除

**批量操作：**
- 多选设备 → 批量删除 / 批量修改状态
- 全选复选框

**导入设备：**
- 下载导入模板 (CSV)
- 上传 CSV 文件 → 预览解析结果 → 确认导入
- 支持 30+ 字段自动列名匹配

**导出设备：**
- 导出全部设备台账为 CSV（含财务、计量等完整信息）

**添加/编辑设备：**
完整编辑页面包含 30+ 字段，分组展示：
- 基本信息：编号、名称、型号、资产编号、分类、母设备
- 财务信息：购置日期、原值、税金、税后费用、发票、合同
- 技术信息：出厂编号、生产厂家、出厂日期、使用年限、软件配置
- 计量信息：溯源方式、计量机构、周期、证书编号、有效期
- 位置信息：归属部门、存放位置
- 其他：是否固定资产、设备来源、备注

### 7.3 用户管理

- 用户列表：ID、名称、角色、电话
- 添加用户：设置 ID、名称、角色、电话、密码
- 编辑用户：修改名称、角色、电话
- 重置密码：可重置为任意密码（默认 123456）
- 删除用户：支持多选批量删除

**角色说明：**
| 角色 | 权限 |
|------|------|
| super_admin（总管理员） | 全部权限，可管理所有用户和设备 |
| admin（仓库管理员） | 设备管理、工单审批、用户管理 |
| user（普通用户） | 浏览设备、借用/归还/调拨设备 |
| viewer（只读用户） | 仅查看设备，不能借用 |

### 7.4 借用工单管理

- **待审批标签**：查看所有待审批借用工单
  - 选择审批人（从管理员列表中选择）
  - 查看工单详情（申请人、设备清单、事由、时间）
  - 通过 / 拒绝操作
- **全部工单标签**：查看所有历史工单
  - 支持按状态筛选、搜索
  - 列自定义显示（可隐藏/显示指定列）
  - 分页浏览

### 7.5 归还工单管理

- **待审批标签**：查看待审批的归还工单
- **全部工单标签**：查看所有归还记录
- 批准归还后，设备自动标记为"在库可用"，持有人清空

### 7.6 数据导出

| 导出类型 | 内容 |
|---------|------|
| 设备台账 | 全部设备详细字段 |
| 借用记录 | 全部借用历史 |
| 借用工单 | 所有借用工单（含设备明细） |
| 归还工单 | 所有归还工单（含设备明细） |
| 用户列表 | 全部用户信息 |

所有导出为 CSV 格式，UTF-8 编码，含 BOM 头（兼容 Excel 直接打开）。

### 7.7 数据备份

- **手动备份**：立即执行一次完整数据备份
- **自动备份**：设置定时自动备份（N 小时/次）
- **备份管理**：查看备份历史列表、下载备份文件（JSON 格式）
- 备份内容：设备、用户、借用记录、工单、归还工单

### 7.8 系统维护

- **清除工单数据**：密码确认后清除所有借用/归还工单、调拨记录、通知，设备恢复为"在库可用"
